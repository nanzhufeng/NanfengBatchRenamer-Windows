# 南枫批量改名

这是一个 Windows 批量改名工具。当前版本重点是安全预览、事务式批量执行、冲突检查、点击复制、拖动多选，以及最近一次改名撤销。

开发上下文、技术栈和目录结构见 [`docs/context.md`](docs/context.md)；稳定业务规则见 [`docs/domain-rules.md`](docs/domain-rules.md)；当前验证与遗留风险见 [`docs/CURRENT_HANDOFF.md`](docs/CURRENT_HANDOFF.md)。

平台说明：本仓库和 Release 仅对应 Windows 版本。应用内名称统一为“南枫批量改名”，仓库及发布资产使用 `Windows` 标识区分平台。

## 启动方式

双击：

```text
启动_南枫批量改名.bat
```

这个 bat 会启动同目录下的 `run_silent.pyw`，命令窗会自动关闭，主程序独立运行。

如果程序启动失败，错误会写入：

```text
logs\app_error.txt
```

普通运行输出会写入：

```text
logs\app_stdout.txt
```

GitHub Release 默认提供 Inno Setup 7 x64 Windows 安装程序。BAT 启动器保留用于源码调试与问题排查。

Windows v1.1.2 发布文件：

```text
NanfengBatchRenamer-Windows-v1.1.2-Setup.exe
NanfengBatchRenamer-Windows-v1.1.2-Setup.exe.sha256
```

## 第一版支持

- 选择文件夹并读取当前目录文件。
- 文件夹路径输入后，可按回车直接读取文件。
- 通过扩展名标签逐个选择筛选项，序列/图片格式和视频格式分组显示。
- 扩展名筛选里的“全部”表示不限制扩展名，会读取当前目录下真实全部文件格式。
- 调整规则里的数字、文本或勾选状态时，新文件名会实时同步预览；数字连续点击时会做短暂合并刷新，减少卡顿。
- 每个规则区域右上角都有独立“重置”按钮，总的“重置规则”按钮仍然保留。
- 底部操作提示会高亮显示，并在几秒后自动清空。
- 删除字符支持开头、结尾，以及“从指定位置开始删除指定数量”的中间删除。
- 点击原文件名、新文件名、扩展名、所在目录、大小、修改时间表头可排序；文件名按数字大小自然排序。
- 表格预览原文件名和新文件名。
- 点击原文件名、新文件名、扩展名、所在目录可复制文字，并在底部用不同颜色提示。
- 在选择列按住鼠标向下拖动，可连续勾选或取消。
- 查找替换。
- 添加文本：前缀、后缀、指定位置插入。
- 删除开头 / 结尾字符。
- 自动编号默认前缀，支持位数、起始值、递增值和分隔符。
- 扩展名统一小写 / 大写。
- 检查冲突和非法文件名。
- 执行改名。
- 仅大小写变化使用临时名中转；批次任一步失败时自动恢复整批原文件，自动恢复失败会生成 JSON 恢复清单。
- 撤销最近一次成功改名。
- 根据当前屏幕可用区域等比缩放字号、控件、间距和表格，支持低分辨率布局。
- 本地日志。

## 第一版暂不支持

- 文件夹改名。
- 子文件夹递归读取。
- 正则替换。
- EXIF / 元数据读取。
- 序列帧智能识别。

## 建议测试流程

1. 先选择 `test_samples` 文件夹。
2. 点击“读取文件”。
3. 在“添加文本”里勾选“前缀”，输入 `shot_`。
4. 勾选“自动编号”，保持默认 `0001` 起始。
5. 点击“预览”。
6. 确认表格里的新文件名没有冲突。
7. 点击“执行改名”。
8. 如需恢复，点击左侧“撤销上次改名”。

## 日志位置

```text
logs
```

每次执行和撤销都会写入日志，方便排查问题。
