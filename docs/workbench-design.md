# 2026-10-12 已确认工作台设计

用户确认的最后可编辑排版为 `precise-preview-refined-details.png`。现由 `src/batch_renamer/ui/workbench.py` 落实，主窗口业务操作继续继承 `app.py`，名称规则、预览、冲突和事务唯一所有者保持 `core/`。

- 基准画布 1820×1130，侧栏206、规则栏320；窗口适配从基准缩放，不能累乘。中性外底 `#EEEEEE`，大卡和列表空白 `#FFFFFF`，内部表面 `#F4F4F4`；无线框，凭明暗和留白分层。主操作、淡杏、淡紫等色直接采用用户南枫转写参考色值。
- 主体为三栏。来源卡第一行路径/选择/读取，第二行全部/图片/视频和可勾选的包含子文件夹；勾选后重新读取包含所有层级，包含扩展名固定在规则总标题右侧。
- 类型筛选保留32逻辑像素固定槽：全部时只隐藏内容；图片仅展示 jpg/png/exr/tif/dpx/psd，视频仅展示 mp4/mov/avi/mkv/ts/flv/wmv/m4v。每组选择独立保留，无选中格式时读取空集，不得退回全部扫描。
- 动作条依次为全选、反选、重置规则、清空列表、预览、检查冲突、执行改名、撤销。左栏不重复撤销、不提供虚构历史页面。
- 动作条左侧为列表与规则组，右侧为文件处理组；两组之间留24逻辑像素间距，均使用一致的浅灰胶囊底，不加线框或分隔线。
- 表格十列顺序不变，权重 `45:45:65:260:300:55:170:75:130:100`；以实际视口分配，包括垂直滚动条出现后的宽度。表头 `#FAFAFA`，顶部左右填满并以18圆角裁切。未使用区域纯白不透明；表格标题/数据居中，长内容提供完整 tooltip 和点击复制。
- 五组规则默认展开，内部参数顺序与原始程序一致，标题行图标/标题/开关/回转图标重置。添加文字的组开关只决定是否应用子规则，不清除输入；勾选子规则自动启用组。扩展名的组开关只决定是否应用大小写转换；更改下拉自动启用，关闭不清除值。
- 数字上下键沿用单击一次单步、260ms延迟长按连发，箭头改为统一线性折角；下拉箭头同步。开关完整42×24命中区，鼠标/Space/焦点状态保留，勾选框明确显示白色勾号。
- 开关焦点使用轻微底色明暗变化，不画黑色或深色外圈，保留键盘焦点和Space操作。
- 自动编号图标为01，扩展名为Aa，添加文字为Tt；设置为标准齿轮，关于为圆圈i。
- 五个规则图标主体分别为清晰的绿、赭金、陶橙、紫、玫红色，加深主体色提高区分度；底座保持中性灰色，标题和模块背景不随图标改色。
- 设置/关于按用户提供的南枫转写窗口结构落实：白色外层、浅灰分区、底部取消/保存或关闭。仅提供真实存在的启动文件类型、恢复路径偏好与功能审阅，不复制转写软件的字幕等业务选项。
- 确认、完成、警告、错误与设置/关于共享 PopupSurface：纯白圆角、不透明前景、轻阴影、中文按钮，避免系统深色背景与深色文字混用。执行确认默认取消，关闭/Esc按取消处理。

验收入口：`python -m unittest discover -s tests -v`、`python -m compileall src tests scripts`、`python scripts/capture_workbench_acceptance.py`。截图只使用隔离演示文件，正式用户文件不得作为自动验收输入。

窗口关闭时自动记住大小与最大化状态，下次打开恢复；首次启动沿用屏幕适配。屏幕可用范围不足时限制恢复尺寸，并重新计算控件比例。验证与截图使用独立临时 QSettings，避免覆盖用户窗口偏好。
