# 南枫批量改名 Windows v1.1.4

本版本修复 Windows 桌面快捷方式仍显示旧方形图标的问题，功能与 `v1.1.3` 保持一致。

## 主要更新

- 安装目录新增带版本号的独立 ICO 文件。
- 桌面和开始菜单快捷方式显式引用该版本化图标，避免 Explorer 继续复用旧缓存。
- 卸载项同步使用版本化图标。
- 图标外轮廓按最终参考图调整为明显的 19% 大圆角，圆角外为真实透明。
- 图标继续保持中性灰白和原有橙绿功能色。

使用小智桌面等第三方桌面整理软件时，升级后若仍显示旧方形图标，请重启桌面整理软件一次。该现象来自整理软件自己的快捷方式位图缓存，不是圆角外被填成白色或深色。

## 安装与卸载

1. 下载 `NanfengBatchRenamer-Windows-v1.1.4-Setup.exe`。
2. 双击并按中文安装向导完成安装。
3. 默认安装到当前用户的本地应用目录，不要求管理员权限。
4. 可通过 Windows“已安装的应用”或开始菜单卸载。

## 已知边界

- 安装包未进行商业代码签名，Windows 可能显示 SmartScreen 提示。
