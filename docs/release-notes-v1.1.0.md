# 南枫批量改名 Windows v1.1.0

本版本改为优先提供 Inno Setup 7 x64 安装程序。

## 主要更新

- 新增两阶段事务改名，支持仅大小写变化和名称互换。
- 批次任一步失败时自动恢复整批原文件；自动恢复不完整时生成 JSON 恢复清单。
- 工作台根据当前屏幕逻辑可用区域等比缩放字号、控件、图标、间距和表格列宽。
- 完成 `1280×720` 至 `2200×1152` 的分辨率回归与 Windows 原生低分辨率截图验证。
- 优化大批量预览，避免逐项重复查询目录；建立 1,000、10,000、50,000 条性能基线。
- 补充主要控件和自定义数字箭头的可访问名称。

## 安装与卸载

1. 下载 `NanfengBatchRenamer-Windows-v1.1.0-Setup.exe`。
2. 双击并按中文安装向导完成安装。
3. 默认安装到当前用户的本地应用目录，不要求管理员权限。
4. 可通过 Windows“已安装的应用”或开始菜单卸载。

## 已知边界

- 安装包未进行商业代码签名，Windows 可能显示 SmartScreen 提示。
- 真实双显示器不同 DPI 跨屏拖动、屏幕阅读器、高对比模式和网络共享文件系统仍需继续验证。
