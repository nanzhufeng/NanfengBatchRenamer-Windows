# 南枫批量改名 Windows v1.1.3

本版本修正中性灰白图标在小尺寸下圆角不明显的问题，功能与 `v1.1.2` 保持一致。

## 主要更新

- 将图标透明圆角半径提高到画布约 12%，在 Windows 小图标下仍可识别。
- 保持文件卡片的中性灰白，以及原有橙色、绿色、背景和右下角文字标识。
- 窗口、任务栏、EXE、安装程序和卸载项继续使用同一图标来源。

## 安装与卸载

1. 下载 `NanfengBatchRenamer-Windows-v1.1.3-Setup.exe`。
2. 双击并按中文安装向导完成安装。
3. 默认安装到当前用户的本地应用目录，不要求管理员权限。
4. 可通过 Windows“已安装的应用”或开始菜单卸载。

## 已知边界

- 安装包未进行商业代码签名，Windows 可能显示 SmartScreen 提示。
