## A. 项目专属事实

- 当前只处理单一目录中的文件，不处理文件夹和子目录。
- 规则链顺序、状态集合、单级撤销和具体 UI 入口属于本项目合同，主位置在 `docs/domain-rules.md`。
- 正式发布是 Windows Inno Setup 7 x64 安装程序；PyInstaller 单文件 EXE 是安装包内部载荷。
- 当前主窗口基准大小与具体列宽是本项目 v1.1.2 的视口实现，不推广为其他工具的固定像素标准。

## B. 跨项目可复用规则

- 批量文件工具必须让预览和执行消费同一规则函数与同一计划对象。
- “全部”筛选应表达“无约束”，不能偷换成当前 UI 选项并集。
- 数字控件把输入准确性与昂贵预览刷新解耦：先准确更新值，再合并刷新派生结果。
- 文件名排序默认使用自然数字语义；表格对比、自由文本输入和侧栏分组允许不同对齐规则。
- 重复规则区使用独立重置，同时保留总重置；复制反馈占用固定区域并自动消失。
- 安装包和便携包必须在名称、内部结构和自动检查中分别建模。

这些规则接入用户级 `nanzhufeng-tool-standard`，不在本项目复制共享正文。

## C. 经授权的长期偏好

仅写入一条小型记忆更新：在批量文件/媒体工作台中，表格和数值控件默认居中，自由文本输入居左；所有派生预览实时同步，但不得牺牲快速点击的输入准确性；平台发布名必须显式区分 Windows/macOS 等。

不写入项目路径、版本号、文件名、截图、设备信息、GitHub 资产、账号或日志内容。

## D. Windows 平台约束

- Windows 文件名非法字符、保留名称、尾点和近 240 字符路径在预览阶段拦截。
- Windows 路径冲突比较按大小写不敏感处理。
- PyInstaller 构建成功不能替代 EXE 启动、标题和响应验证。
- 代码签名、SmartScreen 和全新机器运行只适用于 Windows 交付，不能推广到 macOS 或 Android。

## E. 尚未验证的推测与风险

- 仅大小写变化已在当前 Windows 临时目录验证；网络共享、非 NTFS 文件系统和第三方同步盘策略未验证。
- 核心预览已有 50,000 条基线；真实 50,000 行 `QTableWidget` 刷新、滚动和内存仍未建立可用性基线。
- 高 DPI 完成逻辑尺寸模拟，低分辨率完成离屏截图；真实不同 DPI 双显示器间拖动、屏幕阅读器、高对比模式和键盘完整链路未正式验收。
- 自动回滚与恢复清单已有故障注入测试；杀进程、断电或恢复清单人工执行体验未验证。
- 未签名 EXE 在 SmartScreen 和企业环境中的安装/运行体验。
- 本轮自动窗口截图接口返回系统不支持错误，未形成持久化的最终截图基线；不得用旧品牌截图替代。

## 被否定方案与禁止项

| 方案 | 为什么看似合理 | 失败证据 | 防回归 |
|---|---|---|---|
| 直接复刻 Bulk Rename Utility | 功能齐全且成熟 | 用户明确认为复杂、密度和层级不适合当前任务 | 第一任务工作台合同与目标视口验收 |
| 所有文字机械居中 | 表面统一 | 自由文本输入和左侧分组阅读变差 | UI 合同区分数据展示与文本录入 |
| 右侧规则区依赖滚动 | 能容纳更多控件 | 用户多次指出高度不足和滚动条干扰 | 目标视口无裁切检查，规则行压缩而非隐藏 |
| 数字箭头同时绑定点击与长按重复 | 代码短、看似跟手 | 快速点击出现次数不准 | 快速 25 次点击精确计数测试 |
| “从—到”删除 | 与传统范围选择一致 | 终点必须大于起点，人工设置别扭且不直观 | 位置 + 删除数量语义测试 |
| “全部”=可见扩展名标签并集 | 实现直接 | 无标签格式会被错误排除 | 空过滤条件读取任意扩展名单测 |
| 提示永久停留或每次预览重复提示 | 信息可见 | 状态区被无价值文本占用 | 定时清空，实时预览不写常驻提示 |
| 把 Portable ZIP 命名为 Setup | 用户可能理解为可双击 | 实际没有安装/卸载行为，交付语义错误 | 发布脚本区分 `setup` 与 `portable` |
| 用旧截图代表最终设计 | 获取容易 | 旧品牌、旧布局或被否定控件会污染结论 | 最终基准只认当前代码/Release；截图缺失列风险 |
