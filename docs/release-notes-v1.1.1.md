# 南枫批量改名 Windows v1.1.1

本版本更换软件图标，功能与 `v1.1.0` 保持一致。

## 主要更新

- 使用用户确认的完整原图替换旧“南”字图标。
- 保留原图构图、颜色、背景、文字标识和留白，仅生成 Windows 所需的多尺寸 ICO。
- 统一窗口、任务栏、EXE、安装程序和卸载项图标来源。

## 安装与卸载

1. 下载 `NanfengBatchRenamer-Windows-v1.1.1-Setup.exe`。
2. 双击并按中文安装向导完成安装。
3. 默认安装到当前用户的本地应用目录，不要求管理员权限。
4. 可通过 Windows“已安装的应用”或开始菜单卸载。

## 已知边界

- 安装包未进行商业代码签名，Windows 可能显示 SmartScreen 提示。
