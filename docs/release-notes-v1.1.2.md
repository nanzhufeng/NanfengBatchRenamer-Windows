# 南枫批量改名 Windows v1.1.2

本版本微调软件图标，功能与 `v1.1.1` 保持一致。

## 主要更新

- 在用户确认图标四周增加轻微透明圆角。
- 将文件卡片的暖白调整为偏中性的灰白，保留立体明暗。
- 保留原图主体、比例、背景、橙绿功能色和右下角文字标识。
- 窗口、任务栏、EXE、安装程序和卸载项继续使用同一图标来源。

## 安装与卸载

1. 下载 `NanfengBatchRenamer-Windows-v1.1.2-Setup.exe`。
2. 双击并按中文安装向导完成安装。
3. 默认安装到当前用户的本地应用目录，不要求管理员权限。
4. 可通过 Windows“已安装的应用”或开始菜单卸载。

## 已知边界

- 安装包未进行商业代码签名，Windows 可能显示 SmartScreen 提示。
